Release Record v0.2 · runs on real corpora only

Can this release claim be proven?

Something changed in a deployed system, and someone said the change made it better. Orbit reads the evidence behind that claim and answers two questions: does the evidence support it, and could this evidence ever have settled it.

Step 1 — choose the evidence

One record covers one release pair and one claim. A release carrying three claims gets three records, never one blended verdict.

Four verdicts, and nothing else.

The record answers these and refuses the rest. It does not rank vendors, score safety, infer that a release caused a change, or tell you what to retest.

Release identity

verified / reconstructed / unknown

Which software was actually running on each side. Formatting variants of one label merge automatically and the record lists what it merged. Anything close but not identical is flagged for a named human and never merged: a one-character difference is how Version 10 differs from Version 11.

Exposure

present / missing

Whether the evidence records how much was done — miles, hours, attempts. Without it, counts of events cannot become rates, and a release that simply drove more looks worse.

Claim

supported / not supported / insufficient evidence

Never "false". A claim the evidence cannot reach is not a refuted claim. Exact claims and floor claims are different claims: "+5 points" needs the interval to cover 5, so an observed +38 does not support it, while "at least +5 points" needs the whole interval to clear 5, so +38 does.

Sufficiency

capable / incapable / indeterminate

Whether the study could have detected the claimed effect at all — a property of the design, fixed before any outcome is seen. It comes from the two sample sizes and the rate the design was planned around. Read off the result instead, it is not a capability verdict, and a record with no design rate can never reach supported.

What it will not do.

Missing information degrades a verdict and never raises one. A file with no release labels and no denominator is still accepted and returns unknown and missing, because refusing the file would hide the finding worth reporting.

A significant result from a study that could not reliably have detected the claimed effect is insufficient evidence, not supported.

When the two arms are separate training runs, episode-level noise cannot see run-to-run variation. The interval is too narrow and the detection limit is a lower bound, so that comparison cannot reach supported without a measured run-to-run term, however clean it looks.
