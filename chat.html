Ask which skills the new model broke

Drop an evaluation log into the chat, ask how many episodes an evaluation needs, or look a model up on the boards. Every number the assistant gives comes from the open-source orbit-eval statistics or the arena data, not from the model. Files are processed for the reply and not stored.

Accepts one CSV (version, skill, episode, success) or two or more eval_info.json files, one per version. Prefer no chat? The release check runs in your browser. Usage is limited per visitor to keep the assistant free.
