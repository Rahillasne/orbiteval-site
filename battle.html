Live, from your machine

Pick My own policy above, press Start, and run the one-line command the page prints next to your checkpoint. The arena streams the rollout here and anyone with the session code can watch.

pip install 'lerobot[pusht]'
curl -O https://raw.githubusercontent.com/Rahillasne/orbit-eval/main/tools/orbit_serve.py
python orbit_serve.py --join <session>/b --policy path/to/pretrained_model --env pusht --name "my policy"

Offline, on your GPU

Same seeds for both policies, so the comparison is paired; rounds stop on each task as soon as the referee has resolved it. Then drop the two eval_info.json files in the chat for the same scoreboard with an explanation.

pip install orbit-eval
curl -O https://raw.githubusercontent.com/Rahillasne/orbit-eval/main/tools/orbit_battle.py
python orbit_battle.py --run --a path/to/A/pretrained_model --b path/to/B/pretrained_model \
    --env libero --episodes 50 --batch 10 --seed 1000 --extra --env.task=libero_object
